# EVOFLORA — site do laboratório

Site do **EVOFLORA – Núcleo de Pesquisa em Evolução, Sistemática e Biogeografia da Flora**
(Research Group on Evolution, Systematics, and Biogeography of Flora), coordenado pela
Profa. Verônica Aydos Thode, Departamento de Botânica, UFRGS.
(Repositório criado como `vthodelab`.)

## Estrutura
- `index.html` — página única: Home, Research, Projects, People, Publications, Contact/CV
- `style.css` — estilos (paleta: verde-floresta, terracota, cinza-ardósia)
- `images/`
  - `evoflora_logo.svg` — logo completo (guirlanda + nome), usado no rodapé
  - `evoflora_simbolo.svg` — só a guirlanda, usado no menu e como ícone da aba
  - `pipeline.png` / `pipeline_pt.png` — infográfico em inglês / português
  - `planta_0.jpg` (banner principal), `planta_1.jpg`, `planta_2.jpg` (banners), `veronica.jpg`

## Inglês / português
Todo texto existe nas duas línguas no próprio `index.html`, marcado com `lang="en"` ou `lang="pt"`.
O botão EN/PT no menu mostra só a língua escolhida (a escolha fica salva no navegador).
Também dá para abrir direto em português com `index.html?lang=pt`.
Para editar um texto, altere as duas versões.
